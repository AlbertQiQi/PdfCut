# PDF 2 PNG

一个用于 macOS 的轻量 PDF 切片工具。打开 PDF 后，可以在页面预览上添加、拖动横向和纵向分割线，再把各个区域导出为 PNG 图片。PDF 原文件不会被修改。

## 功能

- 直接打开 PDF，或打开文件夹后从左侧目录树选择 PDF。
- 按页面分别设置分割线；打开 PDF 时会根据页面宽高预设竖线。
- 将竖线等宽排列，或把当前页的分割线应用到全部页面。
- 以 150、300 或 600 DPI 导出 PNG；默认 300 DPI。
- 导出到原 PDF 所在目录，自动避免覆盖已有切片文件夹。

## 使用方法

1. 点击「打开 PDF…」选择文件，或点击「打开文件夹…」并从左侧选择 PDF。
2. 在左侧切换页面，拖动预设分割线，或在右侧添加横线、竖线。点选分割线后可调整百分比位置或删除。
3. 选择 PNG 分辨率，点击「导出 PNG 切片」。

每页的切片按从上到下、从左到右的顺序保存到 `<PDF 文件名>-切片` 文件夹。例如，`document.pdf` 的第 2 页第 1 行第 3 列会生成 `document-切片/page-002-r01-c03.png`。如果目标文件夹已存在，新文件夹会依次使用 `-2`、`-3` 等后缀。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `W` / `S` | 上一页 / 下一页 |
| `Q` / `E` | 新增横线 / 竖线 |
| `Backspace` | 删除选中的分割线 |
| `⌘O` | 打开 PDF |
| `⌘E` | 导出 PNG 切片 |

在输入分割线位置时，字母快捷键不会触发。

## 从源码构建

需要 macOS、Swift 编译器和 Apple Command Line Tools。在本目录运行：

```sh
./build.sh
```

构建结果位于 `dist/PDF 切片.app`。当前构建脚本只生成本机架构的 App，没有进行 Developer ID 签名或 Apple 公证；将 App 提供给其他人下载使用前，还需要检查目标 macOS 版本并完成正式分发签名。
